# Reader 书架与屏幕隐私设计

## 目标

将现有本地 TXT Reader 扩展为可管理的本地书架，并加强阅读时的肩窥保护。所有数据仅保存在扩展 `globalState`；不连接网络、不创建账户、不改动原始 TXT 文件。

## 书架

- 用户选择 TXT 后，Extension Host 弹出中文命名输入框，默认值为文件名（不含扩展名）。取消输入时保留默认名称。
- 书架按最近打开时间降序展示，每项包括自定义书名、进度、最近章节和最后阅读时间。
- 每项提供中文按钮：`打开`、`重命名`、`移除`；按钮拥有简短英文 `title` 属性作为悬停提示。
- `移除` 仅从扩展书架状态删除条目，必须通过 VS Code 原生确认提示；绝不删除本地 TXT。
- 同一 URI 重新导入时，保留原有自定义书名、阅读位置、书签、阅读统计与最近章节；新导入的文件才创建默认记录。

## 每本书状态

使用 `ReaderLibraryEntry` 保存每本书独立数据：URI、自定义名称、最近打开时间、进度、章节与章节内位置、书签、最近章节列表、累计阅读秒数和最近阅读日期。

- 最近章节最多保留 10 条，按最近访问时间排序；点击将恢复该章及其滚动位置。
- 阅读统计只在 Reader 页面可见且正文存在时累计，按分钟节流写入状态；界面显示本次、累计、当前进度和字符数。
- 旧版单本 `ReaderState` 在加载时迁移为当前正在阅读书目的镜像，以保障原有 Reader、Dashboard 与旧状态可继续工作。

## 显示与主题

- Reader 工具栏保持紧凑，仅显示 `打开`、`目录`、`书签`、`显示` 与 `书架` 等中文入口；不再把所有范围控件并排显示。
- `显示` 抽屉提供主题、字号、行距、阅读宽度、显示框高度与透明度；直接拖动即时更新并存储。
- 主题为：系统、纸张、暗色与夜读。夜读使用 VS Code 主题变量附近的低对比配色，不使用渐变或品牌色。

## 屏幕隐私

- 现有“隐藏控件”专注模式继续隐藏标题和左侧导航，仅保留正文与固定恢复按钮。
- 新增 `屏幕遮罩`：手动开启时，正文被不透明的中性遮罩覆盖，页面只显示 `显示文本` 恢复按钮。它不伪造代码或其他内容。
- 可选 `离开模糊`：鼠标离开 Reader 正文区域时以 CSS 轻度模糊文本，鼠标移回时立刻恢复。该选项默认关闭，不影响书架、目录或按钮操作。

## 交互协议与验证

- Webview 只发送 `readerRenameLibrary`、`readerRemoveLibrary`、`readerOpenRecentChapter`、`readerShield` 和现有 `updateSettings` / `saveReader` 消息；文件读取、命名输入与删除确认均由 Extension Host 完成。
- 为状态迁移、重命名、移除（不删文件）、最近章节、显示入口与遮罩状态分别添加自动化测试。
- 最后执行 `npm test`、`npm run package` 并检查 VSIX 中的 `package.json`、`workspace.js` 和 `workspace.css`。
