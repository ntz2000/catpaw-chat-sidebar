# Reader 使用与升级说明

## 当前版本

Workspace 的 Reader 是一个本地 TXT 阅读入口：选择文件后，文本由 Extension Host 读取，阅读位置、基础书签、字号、行距与正文宽度保存在扩展本地状态中。Reader 不直接读取 Webview 文件系统，也不连接任何小说站点或账号。

当前界面中若仍显示 Online Library，它只是已有的公开来源跳转入口；它不属于本地 TXT Reader 的核心功能。

## 后续本地 Reader 设计

后续升级将只围绕用户自己选择的 TXT 文件展开，不包含网络小说站点、登录、抓取、云端同步、EPUB 或 PDF。

- 自动识别 UTF-8、UTF-16、GB18030 与 GBK 等常见编码。
- 根据“第…章/节/回/篇/话”、序章、楔子、尾声等标题生成目录；没有可靠标题时按固定文本块生成章节。
- 提供本地书架、目录、章节跳转、上一章/下一章、搜索、进度和带标签书签。
- 提供滚动与分页两种模式，且只渲染当前章节，避免大 TXT 造成侧栏卡顿。
- Reader 正文可设置字体、字号、行距、宽度和高度，使文本限制在希望的阅读区域内。
- 提供 0%–100% 的正文表层透明度。它只改变 Reader 正文的样式，不会修改 CatPaw / VS Code 原生窗口，也不会改变其他 IDE 区域。

## 快捷键设计

快捷键只会在 Reader 正文获得焦点、且输入框未获得焦点时生效：

| 按键 | 计划行为 |
| --- | --- |
| `W` / `S` | 上一页 / 下一页 |
| `A` / `D` | 上一章 / 下一章 |
| `Space` / `Shift+Space` | 下一页 / 上一页 |
| `B` | 添加书签 |
| `T` | 打开或关闭目录 |
| `/` | 聚焦搜索 |
| `Esc` | 关闭目录或返回正文 |

`Workspace: Quick Hide` 是现有命令：它切换到中性的 Dashboard，不会伪造内容、关闭 IDE 或修改系统窗口。它的快捷键应在 CatPaw / VS Code 的 Keyboard Shortcuts 中按个人偏好配置，而不是由 Reader 覆盖编辑器快捷键。
