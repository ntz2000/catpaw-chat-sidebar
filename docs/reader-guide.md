# Reader 使用与升级说明

## 当前版本

Workspace 的 Reader 是一个本地 TXT 阅读入口：选择文件后，文本由 Extension Host 读取，阅读位置、基础书签、字号、行距与正文宽度保存在扩展本地状态中。Reader 不直接读取 Webview 文件系统，也不连接任何小说站点或账号。

Reader 已只围绕用户自己选择的 TXT 文件实现，不包含网络小说站点、登录、抓取、云端同步、EPUB 或 PDF。

- 自动识别 UTF-8、UTF-16、GB18030 与 GBK 等常见编码。
- 根据“第…章/节/回/篇/话”、序章、楔子、尾声等标题生成目录；没有可靠标题时按固定文本块生成章节。
- 导入时可自定义书名；本地书架支持打开、重命名、移除记录。移除只清理扩展状态，绝不会删除本地 TXT 文件。
- 每本书独立保存进度、书签、最近 10 个章节、累计阅读时间与最近阅读时间；书架按最近打开时间排列。
- 提供目录、章节跳转、上一章/下一章、搜索、进度和带标签书签。
- 提供滚动与分页两种模式，且只渲染当前章节，避免大 TXT 造成侧栏卡顿。
- Reader 正文可设置字体、字号、行距、宽度和高度，使文本限制在希望的阅读区域内。
- 提供 0%–100% 的正文表层透明度。它只改变 Reader 正文的样式，不会修改 CatPaw / VS Code 原生窗口，也不会改变其他 IDE 区域。

## 快捷键设计

翻页快捷键在 Reader 页面全局生效，无需先点击正文；章节只通过鼠标点击目录或按钮选择：

| 按键 | 当前行为 |
| --- | --- |
| `Ctrl+;` | 上一页 |
| `Ctrl+'` | 下一页 |
| `Ctrl+↑` | 透明度增加 5% |
| `Ctrl+↓` | 透明度降低 5% |
| `Ctrl+Alt+R` | 在正文专注模式中恢复 Reader 控件 |

`Workspace: Quick Hide` 是现有命令：它切换到中性的 Dashboard，不会伪造内容、关闭 IDE 或修改系统窗口。它的快捷键应在 CatPaw / VS Code 的 Keyboard Shortcuts 中按个人偏好配置，而不是由 Reader 覆盖编辑器快捷键。

## 状态标记

上述 Reader 能力已在 0.0.25 实现。TXT 不会通过 Webview 直接读文件；界面只接收当前章节的纯文本和目录数据。点击 Reader 的“显示”可快速调整系统、纸张、暗色、夜读主题，以及字号、行距、宽度、高度和透明度；`Ctrl+↑ / Ctrl+↓` 也可调整透明度。隐藏控件会隐藏标题和模块导航，仅保留正文与右下角固定的“恢复”按钮；也可通过 `Ctrl+Alt+R` 恢复。屏幕遮罩只显示中性覆盖层和“显示文本”按钮；离开模糊默认关闭。目录保持高对比且不透明。
